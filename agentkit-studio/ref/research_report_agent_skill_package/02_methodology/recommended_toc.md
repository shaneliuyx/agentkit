# Generic Report Template Presets

Use these as reference presets for `ResearchConfig.report_type`. The selected
profile may be overridden by the user.

## Generic Research Report

```markdown
# Title

## Executive Summary
## Scope and Research Questions
## Background and Context
## Key Findings
## Evidence and Analysis
## Implications or Recommendations
## Limitations and Uncertainty
## References
```

## Technical Report

Use only for technical topics or when the user asks for implementation detail.

```markdown
# Title

## Executive Summary
## Background and Scope
## Key Concepts
## Architecture Overview or Current State
## Methodology
## Implementation Blueprint
## Practical Code or Example Walkthrough
## Governance and Security
## Evaluation and Metrics
## Limitations and Open Questions
## Reflection and Lessons Learned
## Appendix: Code, Diagrams, Glossary, References
```

## Profile Rules

- Code sections are optional and should appear only for technical/product
  implementation reports.
- Diagrams are optional and should clarify architecture, flow, lifecycle, market
  map, policy pathway, or evidence taxonomy when useful.
- Every profile should include limitations/uncertainty and references.
- Evidence-heavy sections should cite sources; navigational sections do not need
  citations.
